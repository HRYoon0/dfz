G015 · 체육 · 모둠 대항

짝카드 활쏘기

과녁 카드를 활로 맞혀 두 장씩 뒤집고 같은 짝을 찾는 모둠 대항 게임입니다. 사수는 조준하고, 나머지 모둠원은 카드 위치를 기억해 말로 도와줍니다.

진행 방법
  1. 모둠 차례마다 사수 1명이 화살 2발로 카드 2장을 엽니다.
  2. 짝이면 1점을 얻고 한 번 더 쏩니다. 아니면 3초 뒤 다시 뒤집히고 다음 모둠으로 넘어갑니다.
  3. 차례가 바뀔 때마다 사수를 교대합니다(앱이 자동으로).
  4. 시간이 끝나면 점수가 높은 모둠이 이깁니다. 짝을 모두 찾으면 새 판!

  • 빨간불 확인 판정 규칙 19개(사수만 조준·쏘기 · 앞뒤 방향 · 문턱 · 빗나감 · 짝이면 한 번 더 · 보여 주기 · 덮기 · 사수 교대 · 다음 모둠 · 예정 시각 · 시간 넘김 · 새 판 · 사수 나감 · 빈 판 합류 · 흔들림 · 약한 흔들기 · 짝만 점수 · 모둠 넘기기)를 하나씩 끄면 각각 검사가 실패했고, 되돌리면 모두 다시 통과했습니다.
  • 컴파일 무대 UguiPairArcheryStage를 이 저장소의 실제 QuizArt.cs와, 나머지 원본 함수의 실제 선언과 같은 모양의 대역에 대고 컴파일했습니다(경고 0, 오류 0).
  • 안 함 원본 소스 대조(읽지 못함), Unity 실행기, 실제 엔진 컴파일, 앱 화면 촬영, 실물 폰·컨트롤러, 윈도 PC.

앱에 붙이려면

  1. 규칙: FlowType 맨 뒤에 PairArchery, GameRuleSet에 flow.pairArcheryMode(easy·normal·hard), 검증기와 스키마(장치 Phone·Controller, 모둠전 허용).
  2. 세션: IsNativeActivity에 넣어 기기 입력이 점수로 바로 가지 않게. 감독의 Award만 HandleActivityInput으로 — 모둠 합계는 기존 팀 집계가 합니다.
  3. 화면: UguiNativeActivities에 감독·무대. 라우터 입력은 HandleInput, 장면마다 SyncRoster → Tick → Sync. 모둠 배정이 SyncRoster보다 먼저여야 합니다.
  4. 폰 화면: 사수가 아닌 사람의 폰에 「지금은 ○○ 모둠 P3 차례」를 띄우면 좋습니다. 폰 페이지는 공용이라 이번엔 안 건드렸습니다.
  5. 출시: GameTitles(제목에 「G015」), 표지, 출시 목록 검사, 포털 사본. 규칙 파일 초안 셋(2·3·4모둠, 300초)을 StreamingAssets/games/ 아래로.
  6. 말 표 12개 언어: pairArchery.hint·turn·pairsLeft·miss·wide·timeout·cleared·team.blue/red/yellow/purple(진행 기록에 ko·en).

실물에서 봐 주셨으면 하는 것

  • 앞뒤 방향 — 앞으로 기울이면 조준선이 위로 갑니다(G002 기울기 미로와 같음). 앱 계약에서 기울기 y는 「앞으로 +」이고 방향키 장치의 ↑ 키도 +라서, 처음 판(콕콕 분류를 따른 +1)은 ↑ 키가 아래로 갔습니다. 같은 까닭으로 기존 「콕콕 분류」도 반대로 갈 것으로 보입니다(공용이라 안 고침). 폰 앞뒤 축은 실물로 재 본 적이 없어, 실물이 반대면 TiltFlipY 하나만 바꿉니다.
  • 조준선 빠르기와 어려움의 흔들림 크기가 알맞은지.
