HTML 게임 「지구를 지켜라! 에코 액션 배틀」(G006 v0.3, 회원님이 주신 HTML 파일)을 이 저장소의 C# 틀(판정 → 감독 → 무대)로 옮겼습니다. 2~4명이 저마다 제 칸에서 같은 때에 떨어지는 물건을 분류하는 게임입니다. 일반쓰레기는 발 구르기, 재활용품은 손뼉으로 처리하고 자연물은 그냥 보냅니다. 원본에 적힌 대로(「실제 발동작·박수의 카메라 인식은 다음 버전」) 입력만 키보드 → 카메라 골격으로 바꾸고 나머지는 원본 그대로 옮겼습니다. 주개발자 게임과 같은 흐름(참가 → 동작 연습 → 시작)을 넣었고, 앱 「웹 게임」에 붙여 넣는 HTML 판(줄인 판)도 함께 올렸습니다. 새 파일만 더했고 기존 파일은 고치지 않았습니다.

지구를 지켜라! 에코 액션 배틀

물건이 아래로 떨어지면 빠르게 판단하세요! 일반쓰레기는 발 구르기, 재활용품은 손뼉치기, 자연물은 가만히 통과시키기!

진행 방법
  1. 일반쓰레기(휴지·과자 봉지·음식 묻은 종이) → 발 구르기
  2. 재활용품(빈 캔·깨끗한 페트병·깨끗한 종이) → 손뼉치기
  3. 자연물(나뭇잎·나비·꽃) → 아무것도 하지 않고 그냥 보내기
  4. 물건이 노란 판정 구역에 왔을 때 움직여요. 정답 100점 + 연속 정답 보너스, 틀리면 −35점.

실물에서 봐 주셨으면 하는 것

  • 발 구르기 — 무릎 높이 차 문턱(몸통 0.3배 들기 · 0.12배 안으로 내림)이 아이들의 가벼운 발 구르기에 알맞은지, 걷거나 옆으로 움직일 때 잘못 잡히지 않는지.
  • 손뼉 — 가슴 앞 손뼉(두 손목 몸통 0.45배 안)이 빠르게 쳐도 잡히는지, 4명이 나란히 섰을 때 팔이 겹쳐 남의 손목을 잡지 않는지.
  • 판정 구역 타이밍 — 카메라 지연을 더해도 보통 빠르기(구역을 약 1초 지남)에서 늦지 않는지.
