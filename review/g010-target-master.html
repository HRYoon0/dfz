G010 움직이는 과녁! 타깃 마스터 — C# 이식 확인

HTML 게임 「움직이는 과녁! 타깃 마스터」(G010 v1.2, 회원님이 주신 HTML 파일)를 이 저장소의 C# 틀(판정 → 감독 → 무대)로 옮겼습니다. 2~4팀이 번갈아 좌우·위아래로 움직이는 과녁을 맞히고, 라운드마다 과녁이 작아지는 팀 게임입니다. 회원님 결정대로 입력만 마우스 클릭 → 폰 기울여 조준 + 단추로 쏘기(G015 짝카드 활쏘기와 같은 조작)로 바꾸고 나머지는 모두 원본대로 옮겼습니다. 주개발자 게임과 같은 흐름(참가 → 동작 연습 → 시작)을 넣었고, 앱 「웹 게임」에 붙여 넣는 HTML 판도 함께 올렸습니다. 새 파일만 더했고 기존 파일은 고치지 않았습니다.

흐름 — 참가 → 동작 연습 → 시작

단계누가무엇
1. 참가 화면앱(그대로)폰·컨트롤러로 참가, 앱이 팀을 고르게 나눕니다(2·3·4팀 규칙 파일). 모자라면 봇이 채웁니다(botFill)
2. 입장 뒤 동작 연습이 게임(TargetMasterPractice)「조준 연습」 — 저마다 폰을 기울여 자기 조준선(팀 색)을 움직여 보고 단추를 한 번. 참가자 전원(봇은 바로 통과)이 누르면 「잘했어요!」 0.8초 뒤 시작. 선생님은 앱의 「바로 시작」/Enter.
3. 게임 시작앱 3초 세기 → 이 게임라운드마다 팀이 차례로 시도 수만큼 이어서 쏩니다. 시도마다 같은 팀 사람이 돌아가며 사수. 다 쏘면 앱이 경기를 닫고 결과 화면(팀 합계)

직접 해 보기

C# 판정과 같은 규칙과 숫자로 움직입니다. 팀마다 두 사람이 서고(합류 순서대로 팀을 번갈아), 지금 사수의 폰 대신 방향키로 조준선을 기울이고 스페이스로 쏩니다. 동작 연습에서는 아직 안 누른 사람부터 차례로 방향키·스페이스를 맡습니다. 「시범 보기」면 모두 봇이 원본 시범 모드처럼 쏩니다. Enter는 선생님의 「바로 시작」.

G010 · 6학년 체육 · 힘·방향·거리 조절

움직이는 과녁! 타깃 마스터

힘은 얼마나? 방향은 어디로? 거리가 달라져도 중심을 향해 도전해요. 2–4팀 · 정확하게, 차분하게!

진행 방법
  1. 라운드마다 팀이 차례로 정해진 시도만큼 이어서 쏴요. 시도마다 팀 안에서 사수가 바뀌어요.
  2. 사수는 폰을 기울여 조준선을 움직이고, 단추를 눌러 쏴요.
  3. 중심 10점, 안쪽 7점, 중간 5점, 바깥 3점, 빗나감 0점.
  4. 라운드마다 과녁이 조금씩 작아지고, 거리 안내가 0.5m 늘어나요.

파일무엇

검증한 것과 안 한 것

  • Unity 맥 Unity 6000.5.9f1, 빌드 대상 Win64(학교 PC와 같은 조건)로 가지를 받아 컴파일 오류 0, G010 EditMode 검사 38건 모두 통과(골라 돌림 — 전체 검사는 아님).
  • .NET 같은 38건을 .NET 8·C# 9·경고를 오류로·NUnit 3.14로도 돌렸습니다(main의 실제 파일과 함께 묶음).
  • 빨간불 확인 판정·연습·감독·무대 규칙 57개를 하나씩 끄면 모두 검사가 실패합니다. 처음엔 5개가 구멍이라 검사 2건을 더하고 3건을 보강했습니다.
  • HTML 판 앱 웹 게임 검사기 통과(위 절).
  • 안 함 앱 화면 촬영(앱에 아직 연결 전이라 앱 화면이 없음), 실물 폰으로 한 판(만든 분들이 확인 — PR #100에서 주개발자께 문의 중), Windows 실행.
